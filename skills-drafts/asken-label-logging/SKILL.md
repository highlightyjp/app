## 目的

食品ラベルの値を正確に写し取り、あすけんに既にある食品か、マイアイテムとして登録する必要があるかを本人が判断できるようにする。登録用の値は出所を付けて示し、公式値とラベル値に差があれば両方を示す。脂質を日ごとに集計する。アプリの操作は本人が行う。

## 発動条件

- 食品ラベルの写真を受け取った（定義による）
- 本作業の追加（本人の決定ではない）: 記録済みの値について、脂質の日次集計だけを依頼された場合は、手順5だけを実行する

## 手順

1. ラベルを読み取る。
   - 1.1 商品名、メーカー名（販売者・製造者）、内容量を、ラベルの記載どおりに写す。
   - 1.2 栄養成分表示の各項目を、項目名・数値・単位・表示の基準量（「100gあたり」「1食(○g)あたり」「1個あたり」など）とともに、ラベルの記載どおりに写す。表示の順番・項目名を変えない。「○〜○」の幅表示や「推定値」「この表示値は目安です」などの注記も写す。
   - 1.3 判読があいまいな数字は、推測で埋めず「未確認」とし、読める範囲（例: 「1?.5」）と理由（反射・かすれ・切れ）を書く。必要なら撮り直しを本人に依頼する。
2. 照合のための検索語を作る。本人がアプリで検索するための検索語（商品名、メーカー名、内容量の組合せ）を示す。Claude 側からアプリを検索しない（「アプリの操作に関する制約」）。
3. DB照合を行う。
   - 3.1 本人から受け取った検索結果の候補ごとに、商品名・メーカー名・基準量・各栄養成分の値を、手順1の値と並べる。
   - 3.2 基準量が違う場合は換算して比べる（`換算値 = 表示値 × 比べる量 ÷ 表示の基準量`）。換算値の区分は「確認済み（算出）」または「未確認（算出）」とする。
   - 3.3 照合結果を「一致／不一致（差の大きい項目を明記）／該当なし」のいずれかで示す。どの候補を使うか、マイアイテムに登録するかの決定は本人が行う。
   - 3.4 本人が検索結果を示せない場合は「照合未実施」とし、「該当なし」と書かない。
4. 該当がなければ、マイアイテム登録用の値を作る。
   - 4.1 公式値を探す。メーカーの公式サイトの商品ページなどの一次情報で栄養成分を確認し、URL・ページ名・取得日を記録する。取得できない場合は「公式値: 未確認」とし、試した経路を残す。
   - 4.2 登録用の値は、公式値を優先する（定義による）。公式値が取得できない項目は、ラベルの値を使い、その旨を書く。
   - 4.3 公式値とラベル値に差がある項目は、両方を併記する（定義による）。差の理由（リニューアル、基準量の違い、地域・ロットの違いなど）は推測で決めず、分かる場合だけ出典付きで書く。
   - 4.4 登録の項目名と単位は、ラベルの表示どおりに示す。あすけんのマイアイテム登録画面の入力項目と単位は確認していない（未確認）ため、画面の項目に合わせた転記は本人が行う。
   - 4.5 本作業の追加（本人の決定ではない）: 登録用の値の各項目に、出所（公式値／ラベル値）と区分を付ける。
5. 脂質を日次で集計する。
   - 5.1 集計する日付と、日付の区切りを本人の設定データから読み込む。ない場合は本人に聞く。
   - 5.2 その日に食べた食品ごとに、脂質の値（基準量あたり）、食べた量、換算後の脂質（`脂質(g) = 基準量あたりの脂質 × 食べた量 ÷ 基準量`）を1行ずつ並べる。
   - 5.3 合計を出す。各行と合計の区分は、入力がすべて確認済みなら「確認済み（算出）」、どれかに未確認（本人申告の量、判読があいまいな値など）が含まれれば「未確認（算出）」とする。
   - 5.4 端数は計算の途中で丸めず、合計を出した後に、ラベルの表示の桁（小数第1位など）にそろえて丸める。丸め方を記録する（本作業の追加。本人の決定ではない）。
   - 5.5 本人の設定データに脂質の目標値があれば、目標値と合計の差を示す。目標値をセッションが決めない。
   - 5.6 アプリに記録されている値と集計値の照合は、本人がアプリの値を示した場合だけ行う。

## 注意点

品質ルール:

- ラベルの値を推測で補わない。判読があいまいな値は未確認とし、撮り直しを依頼する。
- 公式値には URL と取得日を付ける。出典のない値を公式値として扱わない。
- 照合をしていないことを「該当なし」と書かない。
- 換算値・合計は式と入力を示し、区分を「確認済み（算出）」か「未確認（算出）」にする。
- 肯定のみの報告をしない。合計が目標の範囲内でも、未確認の入力を併記する。
- 食事内容・健康状態についての医学的な助言はしない。集計値を示すことに留める（本作業の追加。本人の決定ではない）。

- あすけんのアカウントのパスワード・認証コードを聞かない、扱わない、記録しない。代わりにログインしない。
