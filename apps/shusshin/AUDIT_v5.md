# 監査記録（統一指示書 v5 §13、判定日 2026-10-29）

同一作成者による模擬監査。独立監査ではない。基準は §13.3 をそのまま適用。

| 人格 | 判定 | 根拠 |
| --- | --- | --- |
| P1 利用者 | ○ | iPhone 幅（390px）で横はみ出し 0。ボタン高さ 44〜48px。入力はタップのみ |
| P2 要件整合 | △ | 依頼「模倣し、情報量と精度を上げて」に対し、精度向上は実測できていない（シミュレーションのみ） |
| P3 セキュリティ | △ | 共有DBは Contributor 以上が誰でも pool に書ける（他人の文書の上書き・削除も可能）。読み込み時の NORM で不正形式は除外するが、正しい形式の偽データは防げない。表示は textContent のみで innerHTML に外部データを入れていない |
| P4 保守・運用 | ○ | 定数はエンジン冒頭とビルドに集約。旧版は Artifact の版履歴と Git に残る |
| P5 アクセシビリティ | △ | DADS のフォーカス表示とトークン値を使用。地図の確率は色の濃淡のみだが、同じ情報を「いまの候補」の数値で併記。スクリーンリーダー実機は未確認 |
| P6 データ品質 | ○ | 問題ごとに元データ・作り方・出典を保持し、データ地図で全問を確認できる |
| P7 環境制約 | ○ | 単一HTML（約2.9MB）、外部はGoogle Fontsのみ（読めなければ代替フォント） |
| P8-1 権利 | △ | 政府データは PDL1.0／政府標準利用規約に従い出典と加工の旨を記載。地図は国土数値情報（オープンデータ）。オリジナルの集計データを較正の参考にした点は要・法務確認 |
| P8-2 個人情報 | △ | 出身県と回答を共有DBに保存する（ユーザーIDは含めない）。共有範囲を広げると閲覧者全員が全件を読める。1人1回の印は本人の非公開領域に保存 |

総合判定: 条件付き（× なし、△ あり）。
