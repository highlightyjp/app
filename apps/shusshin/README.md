# 出身県推定 V1

質問に答えると、15歳までにいちばん長く住んだ都道府県を推定する単一HTMLのゲーム。
「出身地、当てます」（nkworks-games.com/shusshin-ken/）のコンセプト（2択の質問で出身地を当てる）を参考にした独自実装。

- 公開版（Artifact）: https://claude.ai/artifact/44ysMnpXUrqrGQQb3LSdWM（現在は本人のみ閲覧可）
- 単体版: `index.html`（ブラウザで直接開ける。みんなの回答の共有はなし）
- 準拠: アプリ作成 統一指示書 v5（`docs/app-build-guide_v5.md`）

## オリジナルとの関係（権利面）

| 項目 | 扱い |

## 的中率（シミュレーション、jsdomではなく Node で計算）

`node tests/sim.js <県あたり試行数> <条件> <乱数種>` で計算（各県12回、ideal は乱数種21、noisy は22）。出身県は人口で重み付けして集計。

| 条件 | 1回目で的中 | 上位3位以内 | 平均質問数 |
| --- | --- | --- | --- |
| ideal（モデルどおりに答える） | 86.9% | 91.5% | 22.9問 |
| noisy（回答率をずらし、5%は無作為に答える） | 75.3% | 81.7% | 24.6問 |

参考（同じ確率表での比較）: オリジナルの判定用確率表（みんなの回答で直した後の値）を本アプリのエンジンで解くと 89.5%（平均20.9問）、オリジナルのエンジンでは 91.3%（平均18.5問）。エンジンの性能は同程度で、差は確率表（データ）による。

注意: シミュレーションは「確率表が正しい」前提の値で、実際の的中率ではない。実際の的中率は、遊んだ人の答えが集まってから共有DBの記録で測る（タイトル画面に表示）。

## データと作り方

`build/` で一次データから `data/questions.json` を生成する。

```
cd apps/shusshin/build
python3 build.py        # 問題（data/questions.json, data/meta.json）
python3 build_map.py    # 地図（data/map.json）
python3 build_html.py   # index.html と dist/artifact.html
```

| 区分 | 元データ（raw/） | 回答率への変換 |
| --- | --- | --- |
| 家計調査（2択 197問） | 総務省統計局 家計調査 品目別都道府県庁所在市ランキング（2023〜2025年平均、407系列）、家計調査年報 2008年 第5表 | ロジット＝1.5×ln(市の値/全国)。2時点ある品目は対数の平均。全国の回答率50%を仮定 |
| 家計調査（多肢 15問） | 同上 | 割合∝(各選択肢の量)^1.5。ガス・移動手段・理美容は金額の割合 |
| 都道府県統計（11問） | 統計でみる都道府県のすがた2026 | 割合の指標はそのまま。代理指標はロジット差1.5倍、件数は対数比 |
| 気象（3問） | 気象庁 平年値（1991〜2020年） 47地点 | 雪は較正式、冬の凍結・猛暑は仮定の式 |
| 学校（1問） | 文部科学省 学校給食実施状況等調査 第6表（平成24〜30年度） | 公立中学校の完全給食率をそのまま |
| 地理（1問） | 海に面しない8県 | 3%の勘違いを残す |
| 郷土料理（1,259問） | 農林水産省「うちの郷土料理」都道府県別掲載 1,365品 | 掲載県45%・同じ地方7%・ほか3.5%（仮定） |

### 較正

統計値→回答率の傾きと郷土料理の回答率は、オリジナルの公開集計（stats.json、2026-10-28取得）のうち内容が重なる問題で当てはめた。

| 対象 | 結果 |
| --- | --- |
| 雪（降雪の深さ合計） | 相関 0.93、logit p = −4.67 + 1.43×ln(降雪+1) |
| 納豆（支出の全国比） | 相関 0.63、傾き 1.11 |
| 鮭とぶり（量の比） | 相関 0.90、傾き 1.57 |
| 肉じゃがの肉（牛・豚の量の比） | 相関 0.92、傾き 1.94 |
| 郷土料理（名前が一致した約30品） | 掲載県 中央値0.62、同じ地方0.07、ほか0.04 |

傾きは中央値の1.5を採用。郷土料理は、較正に使った料理が有名なものに偏るため、掲載県を0.45に下げた。

## みんなの回答（Artifact 共有DB）

- 保存先: `pool/<ランダムID>`（だれの答えか分からない形。ユーザーIDを含めない）。1人1回目のみ（`data/users/<id>/shusshin` に送信済みの印を本人だけが読める形で保存）
- 書き込めるのは共有レベルが Contributor 以上の人。閲覧のみ（Viewer・外部のリンク閲覧者）は読むだけ
- 読み込み時に全件を形式検査（NORM）し、不正なものは使わない
- 文書の上限は 25,000件（プラットフォームの上限）

## 既知の限界

- 家計調査は県庁所在市の値で、県内の地域差を反映しない。2023〜2025年と2008年の値で、それ以前の子ども時代とは差がある
- 統計値→回答率の変換は仮定を含む（全国の回答率50%など）。みんなの回答が集まるまで、確率がずれている問題がある
- 郷土料理の回答率は一律の仮定で、有名な料理ほど低く、知られていない料理ほど高く見積もっている可能性がある
- 中学校給食は平成24〜30年度の値で、それより前に中学生だった人には実態より高い
- 気象は各県1地点
- 社会生活基本調査（都道府県別の行動者率）は今回取得できず、使っていない
- 県民の日の学校休業は一次情報が見つからず、使っていない
