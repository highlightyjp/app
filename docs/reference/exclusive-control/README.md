# 排他制御 参照実装(統一指示書 §15)

追記専用イベントと読込時マージの参照実装と試験。Node.js で実行する(ブラウザでの動作は未確認)。

- `merge.js`: イベント生成・検証・セグメント入出力・HLC・マージ(`materialize`)・遅れ検知(`lagMs`)
- `sha256.js`: 埋込み用の純JS SHA-256
- `test.js`: 収束・オラクル照合・時計・完全性・SHA-256 の試験(`node test.js`)
- `perf.js`: マージ時間の目安(`node perf.js`)

試験のシミュレータとオラクルは参照実装と同じ作成者による。独立した第三者検証ではない。
